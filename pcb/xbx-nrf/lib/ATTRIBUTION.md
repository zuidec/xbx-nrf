# xbx-nrf.kicad_sym: controller project symbols

One file, symbols from three sources:

| Symbol | Source | License |
|---|---|---|
| `+3V6`, `+3V3_TRG`, `+1V8_STICK` | Copies of KiCad's `power:+3V3` / `power:+1V8` (<https://gitlab.com/kicad/libraries>), renamed | [CC BY-SA 4.0][cc] with the [KiCad libraries exception][exc] |
| `RKJXV122400R` | Copy of the SnapMagic symbol in `RKJXV122400R/` (see its `ATTRIBUTION.md`) | [CC BY-SA 4.0][cc] with the SnapMagic Design Exception 1.0 |
| `A3910EEETR-T` | Drawn for this project from the Allegro A3910 datasheet | [CC BY-SA 4.0][cc], like the rest of the file |

The exceptions mean using these symbols in the xbx-nrf design doesn't put the
board under CC BY-SA.

[cc]: https://creativecommons.org/licenses/by-sa/4.0/
[exc]: https://spdx.org/licenses/KiCad-libraries-exception.html
