# PCAL6416A — U4 on the top board

16-bit I2C GPIO expander (NXP, 24-pin HWQFN) on the stock **top board**. Reads
most buttons; our board talks to it over I2C through J3. Tasks:
[[todo#PCAL6416 expander (top board)]].

Sources: [[references/XB1 1914 TOP BOARD.pdf]],
[[references/PCAL6416A-datasheet.pdf]] (Rev. 7.1; § numbers below).

## Key specs

| Parameter | Value | Datasheet |
|---|---|---|
| Supply (VDD(I2C-bus), VDD(P)) | 1.65–5.5 V; both **3.3 V** here | §1 |
| I2C speed | **400 kHz max** | §2 |
| Address | `0b010000A`, ADDR high → **`0x21`** | §7.1, Table 5 |
| Standby current | 1 µA typ / 3.2 µA max | Table 34 |
| Active current (400 kHz reads) | 40 µA typ / 75 µA max | Table 34 |
| Internal pull-up/down | 100 kΩ typ (50–150 kΩ) | §7.4.8, Table 34 |
| Port inputs | 5 V tolerant, 0.7×/0.3× VDD(P) | §2, Table 32 |
| Reset | tw(rst) ≥ 30 ns, trec(rst) ≥ 200 ns | Table 36 |
| Power-up state | All inputs, **pulls disabled**, interrupts masked | §7.4, Table 6 |

## Connections

| U4 pin | Name | Connected to | Notes |
|---|---|---|---|
| 23 | VDD(I2C-bus) | 3.3 V | I2C logic level |
| 21 | VDD(P) | 3.3 V | Core + port supply |
| 18 | ADDR | 3.3 V | → **0x21** |
| 20 | SDA | R41 → TP30 → **J3 pin 7** | C36 51 pF to GND |
| 19 | SCL | TP31 → **J3 pin 5** | C46 100 pF to GND |
| 22 | ~INT | **Not connected** | Poll the inputs |
| 24 | ~RESET | R4 (0 Ω) → **J3 pin 9** | EG2 + C37 to GND; same net as the power hold |
| 9, 25 | VSS, EPAD | GND | |

> [!important] Reset = power hold line
> J3 pin 9 also holds the power latch on (R7 → D26 → Q9). The expander is in
> reset whenever the hold is released, and loses its configuration at every
> power-up. Configure it after asserting the hold.

> [!question] I2C pull-ups
> None on the top board near U4; probably on the stock bottom board. **Put
> pull-ups on our board** (e.g. 4.7 kΩ to 3.3 V) and confirm the top board has
> none.

## Register map

Checked against the datasheet (§7.3, Table 6).

| Cmd | Register | Access | Power-up | Our setting |
|---|---|---|---|---|
| `0x00` / `0x01` | Input port 0 / 1 | R | pin state | **Read every cycle** |
| `0x02` / `0x03` | Output port 0 / 1 | R/W | `0xFF` | Unused |
| `0x04` / `0x05` | Polarity inversion 0 / 1 | R/W | `0x00` | Optional `0xFF` (pressed = 1) |
| `0x06` / `0x07` | Configuration 0 / 1 (1 = input) | R/W | `0xFF` | Leave |
| `0x40`–`0x43` | Output drive strength | R/W | `0xFF` | Unused |
| `0x44` / `0x45` | Input latch 0 / 1 | R/W | `0x00` | Leave off |
| `0x46` / `0x47` | Pull-up/down **enable** 0 / 1 | R/W | **`0x00`** | **`0xFF`**, must be written |
| `0x48` / `0x49` | Pull-up/down **select** 0 / 1 (1 = up) | R/W | `0xFF` | Leave |
| `0x4A` / `0x4B` | Interrupt mask 0 / 1 | R/W | `0xFF` | Leave |
| `0x4C` / `0x4D` | Interrupt status 0 / 1 | R | `0x00` | Unused |
| `0x4F` | Output port configuration | R/W | `0x00` | Unused |

> [!note] Register pairs (§8.1, §8.2)
> Extra bytes in a transfer alternate between the two registers of a pair; they
> don't advance the address.
> - `[0x46, 0xFF, 0xFF]` sets both pull-enable registers.
> - A read at `0x00` returns `Input0, Input1, Input0, …`.
> - The pointer stays on the pair, so later polls can skip the command byte
>   (even byte counts only).

The input latch (§7.4.6) only helps with presses shorter than the 1 ms poll, so
it stays off.

## Firmware notes

### Startup sequence
1. Drive J3 pin 9 high (power hold, releases reset). trec(rst) is 200 ns, so
   I2C can start immediately.
2. Write `[0x46, 0xFF, 0xFF]` (enable pull-ups; select already defaults to up).
3. Optional: `[0x04, 0xFF, 0xFF]` so pressed reads as 1.
4. Read at `0x00` once to set the pointer, then poll every report cycle.

> [!warning] Inputs float until step 2
> Floating inputs read garbage and can draw up to 80 µA each (ΔIDD, Table 34).
> Do step 2 early; ignore reads before it.

### Polling cost
| Transaction | Bits | Time at 400 kHz |
|---|---|---|
| With command byte: `S addr+W 0x00 Sr addr+R d0 d1 P` | ~45 | ~115 µs |
| Pointer already set: `S addr+R d0 d1 P` | ~27 | ~70 µs |

### Current
- ~1 µA standby, ~40 µA while polling continuously.
- Each **held** button: 3.3 V / 100 kΩ ≈ **33 µA** (22–66 µA).
- Nothing when the controller is off (3.3 V rail down).

### Code

```c
#define PCAL6416_ADDR        0x21

#define PCAL_REG_INPUT0      0x00
#define PCAL_REG_POLARITY0   0x04
#define PCAL_REG_CONFIG0     0x06
#define PCAL_REG_PULL_EN0    0x46
#define PCAL_REG_PULL_SEL0   0x48

#define BTN_SHARE  (1u << 0)
#define BTN_X      (1u << 1)
#define BTN_Y      (1u << 3)
#define BTN_RB     (1u << 4)
#define BTN_LB     (1u << 5)
#define BTN_MENU   (1u << 7)
#define BTN_PAIR   (1u << 8)
#define BTN_DUP    (1u << 9)
#define BTN_DRIGHT (1u << 10)
#define BTN_DLEFT  (1u << 11)
#define BTN_DDOWN  (1u << 12)
#define BTN_VIEW   (1u << 13)
#define BTN_A      (1u << 15)
#define BTN_UNUSED_MASK ((1u << 2) | (1u << 6) | (1u << 14))

/* raw = Input0 | (Input1 << 8); active-low without polarity inversion */
static inline uint16_t pcal_buttons(uint16_t raw)
{
    return (uint16_t)(~raw) & (uint16_t)~BTN_UNUSED_MASK;
}
```
