# A3910 — rumble motor drivers (U4, U5 on the bottom board)

Allegro A3910 **dual half-bridge motor driver**. The stock 1914 bottom board uses two of them to drive the four rumble motors, one half-bridge per motor. The new bottom board **copies the stock wiring: 2× A3910, all 8 inputs on GPIOs**. Tasks are tracked in [[todo#Rumble]].

> [!note] Designator clash
> On the stock bottom board, **U4/U5 are the A3910s**. On the top board, **U4 is the [[docs/pcal6416|PCAL6416]]**. Always say which board you mean.

Sources:
- [[references/XB1_1914_BOTTOM_BOARD_SOME_VALUES.pdf]] — stock wiring (read from a high-resolution render)

## Key specs

| Parameter | Value |
|---|---|
| Supply (VBB) | 2.5–5.5 V; **3.6 V** here (J3 pin 1, "Rumble V+") |
| Output current | 500 mA max per output |
| R<sub>DS(on)</sub> at VBB 3 V, 400 mA | high side 1.1 Ω typ / 1.4 Ω max, low side 0.5 Ω typ / 0.65 Ω max |
| Supply current | 0.3 mA typ with both bridges switching at 50 kHz PWM; **< 1 µA in sleep** |
| Logic thresholds | V<sub>IL</sub> ≤ 0.5 V, **V<sub>IH</sub> ≥ VBB/2 = 1.8 V**; 150 mV hysteresis. 3.3 V GPIOs drive it directly |
| Input pull-downs | 100 kΩ internal; 33 µA typ per input held high at 3.3 V |
| Logic input absolute max | −0.3 to 6 V |
| Protection | Crossover (shoot-through) protection; thermal shutdown at 165 °C (15 °C hysteresis) |
| Thermal resistance | 49 °C/W (4-layer JEDEC board), 92 °C/W (2-layer board) |
| Package | 2 × 2 mm DFN-8 with exposed pad (EE), 0.5 mm pitch |
| Orderable part | **A3910EEETR-T** (LCSC C150818) |

## Logic table

The controller motors connect **between OUTx and GND**.

| HINx | LINx | OUTx | Motor (connected to GND) |
|---|---|---|---|
| 0 | 0 | Hi-Z | **Coast.** Sleep if all four inputs are below 100 mV |
| 1 | 0 | High | **Drive** |
| 0 | 1 | Low | **Brake** (motor shorted through the low side) |
| 1 | 1 | Hi-Z | Coast (crossover protection) |

## Stock wiring (bottom board)

| Driver | Output | Motor | Output TP | Input TPs | Clamp diode |
|---|---|---|---|---|---|
| U4 | OUT1 (8) | **LT** impulse trigger | TP27 | TP104–TP107 (U4 inputs) | CR3 |
| U4 | OUT2 (5) | **Heavy** (left grip) | TP28 | ↑ | CR1 |
| U5 | OUT1 (8) | **RT** impulse trigger | TP29 | TP108–TP111 (U5 inputs) | CR4 |
| U5 | OUT2 (5) | **Light** (right grip) | TP30 | ↑ | CR2 |

- Motor terminals: SQ1/SQ2 (LT), SQ3/SQ4 (Heavy), SQ5/SQ6 (RT), SQ7/SQ8 (Light). The second terminal of each motor goes to GND.
- CR1–CR4: clamp diodes from each output to GND.
- C5, C6, C15, C16 (across the motors): **not fitted**.
- VBB decoupling: capacitors are near U4/U5 on the schematic; values not recorded.
- The exact test point → pin assignment for TP104–TP111 hasn't been confirmed. `soc-pinout.txt` gives the SoC pins: U4 pins 1–4 → SoC 49, 50, 48, 47; U5 pins 1–4 → SoC 59, 61, 18, 62.

## Our design

**Decision:** copy the stock wiring. **8 GPIOs** (HIN + LIN for each motor), so every motor can drive, brake and coast.

> [!tip] Freeing pins later
> If pins run short, tie **LIN to GND for Heavy and Light** (−2 GPIOs). Those motors then only drive and coast, which is fine for the grip motors. Keep full control on LT/RT, where fast braking matters for crisp impulse effects.

### Schematic checklist
- [ ] 2× A3910EEETR-T, VBB from J3 pin 1 (3.6 V), exposed pad to GND.
- [ ] VBB decoupling at each driver: at least 1 µF + 100 nF (no values in the stock schematic; check the datasheet application notes and the stock board).
- [ ] Clamp diodes OUTx → GND (copy CR1–CR4), e.g. small Schottky diodes.
- [ ] Optional footprints for capacitors across the motors (like the unfitted C5/C6/C15/C16) for EMI tuning.
- [ ] Motor connection pads matching the stock SQ1–SQ8 positions.
- [ ] 8 GPIOs on PWM-capable pins (on the nRF52840, any GPIO can be a PWM output).

## Firmware notes

- **Strength:** PWM on HINx with LINx = 0 (drive/coast). The nRF52840 has 4 PWM peripherals × 4 channels, so all 8 inputs fit on 2 peripherals.
- **Stop quickly:** HINx = 0, LINx = 1 for a short brake pulse, then return to 0/0.
- **Never needed:** an explicit delay between switching HIN and LIN. The chip has crossover protection, and 1/1 is a safe Hi-Z state.
- **Idle:** drive all 8 inputs **low** so both chips sleep (< 1 µA). Inputs held high each draw about 33 µA through the pull-downs.
- **Power off:** the 3.6 V rail disappears when the latch releases, but set the GPIOs low before releasing the hold anyway, so nothing back-powers the chips through their inputs.
- PWM frequency: the datasheet's supply current figure is given at 50 kHz. Pick a frequency above the audible range (≥ 20 kHz) so the motors don't whine.
