# A3910 — rumble motor drivers (U4, U5 on the bottom board)

Allegro dual half-bridge driver. The stock bottom board uses two, one
half-bridge per rumble motor. **Our board copies this: 2× A3910, 8 GPIOs.**
Tasks: [[todo#Rumble]].

> [!note] Designator clash
> Bottom board **U4/U5 = A3910**; top board **U4 =
> [[docs/pcal6416|PCAL6416]]**.

Sources: [[references/XB1_1914_BOTTOM_BOARD_SOME_VALUES.pdf]],
[[references/A3910-datasheet.pdf]] (Rev. 3), [[references/soc-pinout.txt]].

## Key specs

| Parameter | Value |
|---|---|
| Supply (VBB) | 2.5–5.5 V; **3.6 V** here (J3 pin 1) |
| Output current | 500 mA max per output |
| R<sub>DS(on)</sub> at 3 V, 400 mA | high side 1.1 Ω typ / 1.4 max, low side 0.5 / 0.65 Ω |
| Supply current | 0.3 mA typ (50 kHz PWM); **< 1 µA sleep** |
| Logic thresholds | V<sub>IL</sub> ≤ 0.5 V, **V<sub>IH</sub> ≥ VBB/2 = 1.8 V**: 3.3 V GPIOs are fine |
| Input pull-downs | 100 kΩ; 33 µA per input held high |
| Logic input abs. max | −0.3 to 6 V |
| Protection | Crossover protection; thermal shutdown 165 °C |
| Thermal resistance | 49 °C/W (4-layer), 92 °C/W (2-layer) |
| Package | 2 × 2 mm DFN-8 + exposed pad, 0.5 mm pitch |
| Part | **A3910EEETR-T** (LCSC C150818) |

## Pinout

| Pin | Name | Function |
|---|---|---|
| 1 | HIN1 | High-side input, bridge 1 |
| 2 | LIN1 | Low-side input, bridge 1 |
| 3 | LIN2 | Low-side input, bridge 2 |
| 4 | HIN2 | High-side input, bridge 2 |
| 5 | OUT2 | Output 2 |
| 6 | GND | Ground |
| 7 | VBB | Supply |
| 8 | OUT1 | Output 1 |
| 9 (EP) | PAD | → GND (thermal) |

## Logic table

Motors connect **between OUTx and GND**.

| HINx | LINx | OUTx | Motor |
|---|---|---|---|
| 0 | 0 | Hi-Z | **Coast**; sleep if all four inputs < 100 mV |
| 1 | 0 | High | **Drive** |
| 0 | 1 | Low | **Brake** |
| 1 | 1 | Hi-Z | Coast (crossover protection) |

## Stock wiring (bottom board)

| Driver | Output | Motor | Output TP | Input TPs | Clamp diode |
|---|---|---|---|---|---|
| U4 | OUT1 (8) | **LT** impulse trigger | TP27 | TP104–TP107 | CR3 |
| U4 | OUT2 (5) | **Heavy** (left grip) | TP28 | ↑ | CR1 |
| U5 | OUT1 (8) | **RT** impulse trigger | TP29 | TP108–TP111 | CR4 |
| U5 | OUT2 (5) | **Light** (right grip) | TP30 | ↑ | CR2 |

- Motor pads: SQ1/2 (LT), SQ3/4 (Heavy), SQ5/6 (RT), SQ7/8 (Light); second
  terminal to GND.
- CR1–CR4: clamp diodes output → GND. C5/C6/C15/C16 across the motors: not
  fitted. VBB decoupling values: not recorded.
- SoC pins (from `soc-pinout.txt`): U4 pins 1–4 → 49, 50, 48, 47; U5 pins 1–4 →
  59, 61, 18, 62. TP → pin mapping unconfirmed.

## Our design

8 GPIOs (HIN + LIN per motor): every motor can drive, brake and coast.

> [!tip] Freeing pins later
> Tie **LIN to GND on Heavy and Light** (−2 GPIOs). They then only drive and
> coast, which is fine for grip motors; LT/RT keep fast braking.

- [ ] 2× A3910EEETR-T, VBB from J3 pin 1, exposed pad to GND.
- [ ] VBB decoupling per driver, ≥ 1 µF + 100 nF (check against the stock

- [ ] Clamp diodes OUTx → GND (small Schottky, like CR1–CR4).
- [ ] Optional footprints for capacitors across the motors (EMI).
- [ ] Motor pads at the stock SQ1–SQ8 positions.
- [ ] 8 GPIOs (any nRF52840 pin can do PWM).

## Firmware notes

- **Strength:** PWM on HINx, LINx = 0. All 8 inputs fit on 2 of the 4 PWM
  peripherals.
- **Stop:** HINx = 0, LINx = 1 briefly, then 0/0.
- No dead time needed between HIN and LIN (crossover protection).
- **Idle:** all inputs low → both chips sleep.
- **Power off:** set the inputs low before releasing the hold, so the chips
  aren't back-powered through them.
- PWM ≥ 20 kHz, so the motors don't whine.
